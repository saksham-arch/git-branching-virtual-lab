## Design Context

### Users
TY B Tech Computer Engineering students following SVU–KJSCE 2023_1.0, practising Django and Python laboratories.

### Brand Personality
Academic, direct, familiar. Instructions should help students perform and explain experiments.

### Aesthetic Direction
Follow the Virtual Labs section-based interface: white canvas, blue headings and links, orange divider, persistent left navigation. No marketing hero, decorative dashboards, gradients, or card grids. This is an independent teaching project, not an official MoE site.

### Design Principles
- Keep theory, procedure, practical work and assessment together.
- Use working server behavior and explicit errors.
- Preserve the original Git experiment.
- Keep keyboard navigation and narrow screens usable.
